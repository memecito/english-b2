## 4. Puntos discutibles del material

- **used-to-vs-would**: marca *I would smoke when I was a teenager* como
  incorrecto. Es demasiado estricto: *would* necesita un marco temporal
  pasado ya establecido, y *when I was a teenager* lo da. Regla segura
  para el examen: *used to* para introducir el hábito y para estados;
  *would* solo para acciones repetidas, una vez fijado el contexto.
- **relative adverbs**: el ejemplo con *why* sin antecedente (*I don't
  have any idea why…*) es una pregunta indirecta, no una relative clause
  (ya anotado en la teoría del juego).
